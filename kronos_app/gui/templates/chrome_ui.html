Kronos Foundation Model Architecture & Integrity Framework

Kronos adalah *Decoder-Only Autoregressive Foundation Model* untuk memodelkan struktur pasar keuangan global secara probabilistik murni.

  • Strict Data Integrity: Menghapus seluruh fallback data sintetis. Jika Dukascopy Swiss ECN tidak tersedia dan cache kadaluarsa, status eksplisit DATA UNAVAILABLE ditampilkan.
  • Exact Timeframes & Horizons: M1 (300 candles = 5 jam), M5 (288 candles = 24 jam / 1 hari). Tidak ada pemotongan horizon diam-diam.
  • Sampling Convergence Diagnostics: Menguji kestabilan distribusi Monte Carlo (10 - 10.000 sampel) antar partisi sampel independen. Menandai status CONVERGED, LOW CONFIDENCE, atau UNSTABLE DISTRIBUTION.
  • Pemisahan Probabilitas: Distribusi Monte Carlo model dibedakan secara tegas dari probabilitas empiris historis (hasil walk-forward).
  • Zero Look-Ahead Validation: Validasi out-of-sample historis untuk XAUUSD M1 dan M5 dievaluasi secara terpisah terhadap baseline Last Close, Drift, Random Walk, dan Volatility Corridor.
